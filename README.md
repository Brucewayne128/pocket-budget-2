# Pocket Budget 2

A copy of [Pocket Budget](https://github.com/Brucewayne128/pocket-budget) that also runs as a full app on iPhone in Safari. The original is unchanged.

- **iPhone:** open https://brucewayne128.github.io/pocket-budget-2/ in Safari, then Share → Add to Home Screen, and open it from there. You get your own budget you can edit, just like on Android.
- **Android:** https://github.com/Brucewayne128/pocket-budget-2/releases/latest/download/PocketBudget2.apk (installs as "Pocket Budget 2", next to the original).
- Each phone has its own budget. Share it with the QR code / link (view only), same as before.
- Uses the same Firebase project as the original (see SETUP.md). Budgets are kept separate.
